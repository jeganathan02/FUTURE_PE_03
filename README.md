# AI SEO Blog & Content Cluster Generator

This repository contains a complete SEO Content Cluster for a **Coaching Center in Chennai** (specifically focusing on NEET/JEE competitive exam coaching). It demonstrates how to use AI and prompt engineering to create a ranking-focused content system based on the Hub-and-Spoke (Pillar and Cluster) SEO model.

## 🎯 Objective
To provide a structured prompt workflow that generates:
- SEO blog outlines (H1–H3)
- Long-form, helpful pillar content
- Content clusters around a main topic
- Local SEO adapted content (Chennai + Coaching)
- Business-focused content that drives leads and builds trust

## 📁 Repository Structure

- `/prompts`: Contains the reusable AI prompts designed to generate content clusters, pillar blogs, and supporting blogs for any local business.
- `/content`: Contains the generated content for a mock business ("Chennai Premier NEET Academy"), including 1 pillar blog and 4 supporting blogs.
- `keyword_strategy.md`: Explains the keywords, search intent, and internal linking strategy used for this content cluster.

## 🏪 Business Scenario
**Business Type:** Educational Coaching Center
**Location:** Chennai, Tamil Nadu, India
**Specialization:** NEET (Medical) Entrance Exam Preparation
**Business Goal:** Increase local organic traffic, build authority with parents and students, and drive admissions.

## 🚀 How to Use the Prompts
You can use the prompts located in the `/prompts` folder with any LLM (ChatGPT, Claude, Gemini) to replicate this strategy for a different business.

1. Start with the `content_cluster_prompt.txt` to get your strategy and topic ideas.
2. Use the `pillar_blog_prompt.txt` to write the long-form main article.
3. Use the `supporting_blog_prompt.txt` to write the smaller cluster articles, making sure to internally link them to the pillar blog.
